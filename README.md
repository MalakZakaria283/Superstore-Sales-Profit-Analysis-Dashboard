# 📊 Superstore Sales & Profit Analysis Dashboard

An executive-level, interactive two-page Power BI dashboard designed to analyze high-level sales performance, product profitability, and regional distributions.

---

## 🛠️ Key Features & Interactivity
- **Executive Analysis (Page 1):** Highlights top KPIs (Total Sales, Total Profit, Profit Margin %, YoY Growth) alongside category volume and top 5 products by sales.
- **Product Analysis (Page 2):** In-depth evaluation of product profitability, category breakdown trees, and active catalog range metrics.
- **Interactive Slicers:** Dynamic filtering by Year, Quarter, Region, and Category across views.
- **Cross-Filtering & Visuals:** Integrated cross-filtering between visuals, green data bars for performance tables, and dedicated text-based analytical summaries.

---

## 📐 Data Modeling & DAX Measures
- **Data Model:** Clean data structure built from Superstore transactional records with established attributes and categories.
- **DAX Calculations:** Custom measures implemented for core business metrics and historical comparisons, including:
  - `Total Revenue`
  - `Total Profit`
  - `Profit Margin %`
  - `YoY Growth %` (via time intelligence functions)

---

## 📂 Repository Contents
- **`*.pbix` File:** Complete Power BI report file with interactive visuals and DAX calculations.
- **`*.xlsx` File:** Corresponding Excel file with preprocessing and complementary dashboard representation.
- **Dashboard Screenshots:** High-resolution previews of Page 1 and Page 2.
